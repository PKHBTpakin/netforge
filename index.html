คู่มือใช้งาน NetForge
1. ใส่แผนก
กรอกชื่อ + จำนวนเครื่องเอง หรือกด EXAMPLE เลือกชุดสำเร็จรูป 6 แบบ
ระบบคำนวณ VLSM ให้ทันทีทุกครั้งที่แก้ ไม่ต้องกดคำนวณซ้ำ
2. ปุ่มไม้กายสิทธิ์ ข้าง Calculate
หา Base ที่พอดีที่สุดให้อัตโนมัติ — ลดพื้นที่เหลือทิ้งได้มาก
ในโหมด IPv6 จะเติมค่ามาตรฐานและแก้ prefix ที่ตั้งผิดให้เอง
3. อ่านแผงสรุปใต้ตาราง
แยกให้เห็น ใช้จริง / เสียจากการปัด / สำรองเผื่อโต
พร้อมบอกว่าแต่ละแผนกเพิ่มเครื่องได้อีกกี่ตัวโดยไม่เสีย IP เพิ่ม
4. จัดผังบน Canvas
ลากอุปกรณ์ได้อิสระ วาง PC/Server เพิ่มเอง คลิกโหนดเพื่อแก้รายละเอียด
ล้อเมาส์ = ย่อ/ขยาย · ลากที่ว่าง = เลื่อนผัง · ปุ่ม ⛶ = เห็นครบพอดีกรอบ
5. แท็บล่างมี 3 อย่าง
IP TABLE ผลคำนวณ · CLI CONFIG คำสั่ง Cisco พร้อมคัดลอก · NET TOOLS Wildcard Mask และ Route Summary
วาง Router สาขา
กดปุ่ม Router มุมขวาบนของ Canvas แล้วคลิกตำแหน่งที่ต้องการ
เชื่อมเป็นลิงก์ WAN
กด Connect แล้วคลิก Router สองตัว — ระบบจอง /30 ให้อัตโนมัติ
ดูเลข IP ทั้งสองฝั่งได้ที่ตาราง WAN ใต้แท็บ IP TABLE
ย้ายแผนกไปอยู่สาขา
ลาก Router สาขาไปเชื่อมกับ Switch ของแผนกใด แผนกนั้นจะย้ายไปอยู่หลังสาขานั้น
สายจาก Router หลักถูกตัดออกเองอัตโนมัติ
config แยกต่อ Router
แท็บ CLI จะมีปุ่มเลือกดูทีละตัว
สำนักงานใหญ่ได้ static route ไปแต่ละสาขา · สาขาได้ default route กลับต้นทาง
คลังโปรเจกต์ (ปุ่ม LIBRARY)
เก็บงานหลายชิ้นไว้ในเบราว์เซอร์ เปิดกลับมาได้ทันที ไม่ต้องสมัครสมาชิก
ข้อมูลอยู่ในเครื่องคุณเท่านั้น ไม่ถูกส่งออกไปไหน
ลิงก์แชร์
ฝังทั้งโปรเจกต์ไว้ในตัว URL — ส่งลิงก์เดียวให้คนอื่นเปิดงานได้เลย ไม่ต้องแนบไฟล์
ปุ่ม EXPORT

.csv ตาราง IP เปิดด้วย Excel · .txt คำสั่ง CLI ทุกอุปกรณ์ · .json ไฟล์โปรเจกต์
