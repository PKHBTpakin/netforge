ยินดีต้อนรับสู่ NetForge

เครื่องมือคำนวณ VLSM/IPv6 พร้อมจำลอง Topology เครือข่าย ใช้งานตามลำดับนี้ได้เลย

1. เพิ่มแผนก
กรอกชื่อ + จำนวน Host เอง หรือกด EXAMPLE เลือกชุดข้อมูลสำเร็จรูป
2. คำนวณอัตโนมัติ
ระบบคำนวณ VLSM (และ IPv6 ถ้าตั้งค่า) ให้ทันทีทุกครั้งที่แก้ไขข้อมูล
3. จัดการ Topology
ลากอุปกรณ์ ลากเชื่อมสายบน Canvas ฝั่งขวาได้อิสระ
4. Export คำสั่ง CLI
คัดลอกคำสั่ง Cisco IOS ไปวางใช้กับอุปกรณ์จริงได้ทันที
