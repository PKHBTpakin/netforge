คู่มือใช้งาน NetForge
โปรแกรมนี้ทำอะไร
ช่วยแบ่งเลข IP ให้แต่ละแผนกในบริษัท โดยดูจากว่าแผนกนั้นมีเครื่องกี่เครื่องจริง ๆ แผนกใหญ่ก็ได้เยอะ แผนกเล็กก็ได้น้อย ไม่ต้องแบ่งเท่ากันหมด
วิธีแบ่งแบบนี้มีชื่อเรียกว่า VLSM
พอแบ่งเสร็จ มันจะวาดผังให้ดูด้วยว่าอะไรต่อกับอะไร แล้วเขียนคำสั่งสำหรับใส่ในอุปกรณ์ Cisco ให้เลย
1. ใส่รายชื่อแผนก
พิมพ์ชื่อแผนกกับจำนวนเครื่องลงในช่องทางซ้ายมือ
ถ้ายังไม่รู้จะเริ่มยังไง กดปุ่ม EXAMPLE แล้วเลือกตัวอย่างสำเร็จรูปได้ 8 ชุด
แก้ตัวเลขตรงไหนก็ได้ มันคิดให้ใหม่ทันที ไม่ต้องกดปุ่มคำนวณซ้ำ
2. ให้โปรแกรมเลือกเลขตั้งต้นให้
ช่อง Base คือเลข IP ก้อนใหญ่ที่เราจะเอามาแบ่งให้ทุกแผนก
ถ้าไม่รู้ว่าควรใส่เลขอะไร กดปุ่มรูปไม้กายสิทธิ์ข้างปุ่ม Calculate ได้เลย
มันจะหาก้อนที่เล็กที่สุดที่ยังพอแบ่งครบทุกแผนกให้เอง จะได้ไม่เหลือ IP ทิ้งไว้เยอะเกินจำเป็น
3. ดูว่าใช้ IP ไปคุ้มไหม
แผงใต้ตารางจะบอกว่า IP ที่มีถูกใช้ไปกับอะไรบ้าง แยกเป็นสามส่วน คือส่วนที่ได้ใช้จริง ส่วนที่เสียไปเพราะต้องปัดขนาดขึ้น และส่วนที่เหลือไว้เผื่อเพิ่มเครื่องทีหลัง
แล้วยังบอกด้วยว่าแต่ละแผนกเพิ่มเครื่องได้อีกกี่เครื่อง โดยไม่ต้องไปขอ IP เพิ่ม
4. จัดผังเครือข่าย
ผังตรงกลางลากย้ายได้ทุกชิ้น อยากดูรายละเอียดตัวไหนก็คลิกที่ตัวนั้น
ปุ่มมุมขวาบนไว้เพิ่มเครื่องคอม เซิร์ฟเวอร์ หรือ Router เข้าไปในผัง
หมุนล้อเมาส์ = ย่อขยาย ลากที่ว่าง = เลื่อนผัง กดปุ่มขยายเต็มกรอบ = เห็นทุกอย่างพอดีจอ
5. ใส่แปลนอาคารเป็นพื้นหลัง (ถ้าต้องการ)
ถ้ามีรูปแปลนตึก เอามาวางเป็นพื้นหลังได้ แล้วลากอุปกรณ์ไปวางตรงจุดที่จะติดตั้งจริง
กดปุ่ม แปลน มุมขวาบน เลือกรูป แล้วลากรูปให้เข้าที่ ปรับความจางกับขนาดได้
จัดเสร็จแล้วกดล็อก ไม่งั้นเวลาลากผังจะไปโดนรูปแทน
6. ดูผลลัพธ์ที่แท็บด้านล่าง
IP TABLE คือตารางสรุปว่าแต่ละแผนกได้ IP ช่วงไหน
CLI CONFIG คือคำสั่งสำหรับตั้งค่าอุปกรณ์ Cisco คัดลอกไปวางบนอุปกรณ์ได้เลย
NET TOOLS เป็นเครื่องมือเสริม ไว้หา Wildcard Mask และรวมเส้นทางหลายเส้นให้เหลือเส้นเดียว
7. อยากฝึกคำนวณเองบ้าง
แท็บ ฝึกทำโจทย์ จะกลับด้านกัน คือโปรแกรมออกโจทย์ให้ แล้วคุณคำนวณเอง
กดตรวจแล้วมันจะบอกเป็นช่อง ๆ ว่าถูกหรือผิด และถ้าผิดจะบอกด้วยว่าพลาดที่ขั้นตอนไหน ไม่ใช่แค่บอกว่าผิด
เลือกความยากได้ 3 ระดับ และเอาโจทย์ที่ทำอยู่ไปทำต่อเป็นงานจริงเพื่อดูผังกับคำสั่งได้ด้วย
อ่านตรงนี้ก่อน
ในผังจะมี Router ตัวหลักชื่อ Router-01 ให้มาตั้งแต่แรกหนึ่งตัว ลบทิ้งไม่ได้
ส่วนปุ่ม Router มุมขวาบน กดแล้วจะได้ Router ของสาขา เสมอ ไม่ใช่ Router ตัวหลักอีกตัว

Router สาขาที่เพิ่งวางลงไป จะยังใช้ไม่ได้ ต้องลากสายไปเชื่อมกับ Router ตัวอื่นก่อน
ถ้าลืมทำ สาขานั้นจะไม่มีเลข IP และแผนกที่ย้ายไปอยู่กับมันจะคุยกับที่อื่นไม่ได้เลย

ถ้าอยากเห็นตัวอย่างที่ต่อเสร็จแล้ว กดปุ่ม EXAMPLE แล้วเลือกชุดที่มีป้าย 2 สาขา หรือ 3 สาขา
1. วาง Router ของสาขา
กดปุ่ม Router ที่มุมขวาบนของผัง แล้วคลิกตรงตำแหน่งที่อยากวาง
ตอนนี้ Router ตัวนั้นจะมีกรอบสีเหลืองและเครื่องหมายตกใจกำกับไว้ แปลว่ายังใช้งานไม่ได้
2. ลากสายไปเชื่อมกับ Router-01 (ห้ามข้ามขั้นตอนนี้)
กดปุ่ม Connect แล้วคลิก Router สองตัวที่จะเชื่อมกัน
โปรแกรมจะแบ่งเลข IP ให้สายเส้นนี้เอง โดยใช้ขนาด /30 ซึ่งให้เลขใช้ได้พอดี 2 เบอร์ ตรงกับที่ต้องใช้สองฝั่ง
เมื่อเชื่อมสำเร็จ กรอบสีเหลืองจะหายไป และดูเลข IP ของทั้งสองฝั่งได้ที่ตาราง WAN ในแท็บ IP TABLE
3. ย้ายแผนกไปอยู่กับสาขา
อยากให้แผนกไหนย้ายไปอยู่กับสาขา ก็ลากสายจาก Router สาขาไปหา Switch ของแผนกนั้น
สายเดิมที่ต่อกับ Router ตัวหลักจะถูกตัดออกให้เอง ไม่ต้องไปลบ
4. ดูคำสั่งของ Router แต่ละตัว
ในแท็บ CLI CONFIG มีปุ่มให้เลือกดูทีละตัว เพราะแต่ละ Router ตั้งค่าไม่เหมือนกัน
สำนักงานใหญ่จะได้เส้นทางที่ระบุชัดเจนว่าจะไปหาแต่ละสาขาทางไหน ส่วนสาขาจะได้เส้นทางแบบส่งกลับมาที่สำนักงานใหญ่ทางเดียว เพราะสาขามีทางออกอยู่ทางเดียวอยู่แล้ว
5. เรื่องสัญญาณนาฬิกาของสายอนุกรม
สายอนุกรมต้องมีฝั่งหนึ่งเป็นคนจ่ายสัญญาณนาฬิกา เรียกว่าฝั่ง DCE ซึ่งเป็นฝั่งเดียวที่ต้องมีคำสั่ง clock rate ถ้าฝั่งนั้นไม่ได้ตั้ง สายจะไม่ขึ้นเลยทั้งที่ IP ถูกหมดแล้ว
โปรแกรมสร้างคำสั่งนี้ให้แล้ว โดยเดาว่า Router หลักเป็นฝั่ง DCE ถ้าของจริงเสียบสายกลับด้าน กดปุ่มสลับได้ที่คอลัมน์สุดท้ายของตาราง WAN ใต้แท็บ IP TABLE
ข้อควรรู้เรื่องรูปแบบการต่อ
เพิ่มสาขาได้ไม่จำกัด แต่ควรต่อแบบให้ทุกสาขาวิ่งเข้าหา Router ตัวหลักโดยตรง
ยังไม่รองรับการต่อแบบเรียงต่อกันเป็นทอด ๆ เช่นสำนักงานใหญ่ต่อไปสาขา A แล้วสาขา A ต่อไปสาขา B อีกที เพราะโปรแกรมสร้างเส้นทางให้เฉพาะอุปกรณ์ที่ต่อสายถึงกันโดยตรงเท่านั้น ถ้าต่อแบบนั้นสาขาที่อยู่ปลายสุดจะติดต่อกับสำนักงานใหญ่ไม่ได้
เก็บงานไว้หลายชิ้น (ปุ่ม LIBRARY)
เก็บงานได้หลายชิ้นไว้ในเบราว์เซอร์ อยากกลับมาดูชิ้นไหนก็กดเปิดได้ทันที ไม่ต้องสมัครสมาชิก
ข้อมูลทั้งหมดอยู่ในเครื่องของคุณเท่านั้น ไม่ได้ถูกส่งไปเก็บไว้ที่อื่น
ส่งงานให้คนอื่นดูด้วยลิงก์
โปรแกรมจะเก็บงานทั้งหมดไว้ในตัวลิงก์เลย ส่งลิงก์เดียวให้เพื่อนหรืออาจารย์ก็เปิดดูได้ ไม่ต้องแนบไฟล์ตามไปด้วย
ยกเว้นรูปแปลนอาคารที่จะไม่ติดไปกับลิงก์ เพราะไฟล์รูปใหญ่เกินกว่าจะใส่ในลิงก์ได้ ถ้าอยากส่งรูปไปด้วยให้ใช้ปุ่ม SAVE แล้วส่งเป็นไฟล์แทน
